# Sokoban VM — Кроссплатформенная ретро-игра

Семестровый проект по разработке кроссплатформенной ретро-игры с разделением на низкоуровневое ядро и платформо-независимую логику.

## Архитектура
- **`core/`** — низкоуровневое ядро стековой виртуальной машины на чистом **C99** (без внешних зависимостей, 15 опкодов, аппаратно-независимое чтение Big-Endian).
- **`game/`** — транслятор логики игры Sokoban на Python (`build_rom.py`), компилирующий правила и карту уровня в байт-код (`rom_data.h`).
- **`platforms/`** — тонкие платформенные бэкенды ввода-вывода:
  1. **Windows** (`win_console.c`) — нативное консольное приложение через WinAPI.
  2. **Web** (`web_wasm.c`) — порт для компиляции в WebAssembly (Emscripten).
  3. **Bare-metal / Микроконтроллеры** (`arduino_uno.ino`) — прошивка для 8-битного AVR (Arduino Uno).
- **`tests/`** — модульные тесты инструкций ВМ и фаззинг-тестирование (10 000 мутаций байт-кода и ввода).

## Поддерживаемые архитектуры и ОС
- **Процессоры:** x86_64 (64-бит, Little-Endian) и AVR ATmega328P (8-бит).
- **Категории ОС:** Windows, Web (WASM), Bare-metal (Arduino).
