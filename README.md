# Sokoban VM — Кроссплатформенная ретро-игра

Семестровый проект по разработке простой кроссплатформенной ретро-игры (**Sokoban**) с разделением на низкоуровневое системное ядро и платформо-независимую игровую логику.

## Архитектура проекта

Проект разделён на три изолированных слоя:

1. **Низкоуровневое ядро (`core/`)**
   - Написано на чистом системном языке **C99** (`vm.h`, `vm.c`) без использования сторонних библиотек.
   - Реализует собственную **стековую виртуальную машину** (15 опкодов, 4 КБ ОЗУ, стек на 64 значения, виртуальный фреймбуфер `12x10`).
   - Обеспечивает аппаратную независимость: все 16-битные аргументы декодируются побитово в формате **Big-Endian**, а для данных используются строго фиксированные типы (`uint8_t`, `int16_t`, `uint16_t`).

2. **Игровая логика (`game/`)**
   - Правила игры и карта уровня описаны отдельно от ядра на собственном мини-ассемблере и компилируются скриптом `build_rom.py` в бинарный образ картриджа (`rom_data.h`).
   - Игровая логика исполняется исключительно внутри виртуальной машины.

3. **Платформенные бэкенды (`platforms/`)**
   - Тонкие слои ввода-вывода, связывающие виртуальный экран и кнопки ядра с конкретной средой.

## Поддерживаемые платформы и архитектуры

### Процессоры (2+ архитектуры с разной разрядностью)
- **x86_64** — 64-битная архитектура (Little-Endian), нативный запуск на ПК.
- **AVR (ATmega328P / ATmega2560)** — 8-битный микроконтроллер (Arduino).

### Операционные системы (3+ категории)
1. **Windows** (`platforms/win_console.c`) — нативное консольное приложение с отрисовкой через WinAPI.
2. **Web** (`platforms/web_wasm.c`, `platforms/index.html`) — компиляция ядра в **WebAssembly (WASM)** через Emscripten и запуск в браузере.
3. **Bare-metal / Микроконтроллеры** (`platforms/arduino_uno.ino`) — прошивка без ОС с выводом через UART (Serial Monitor).
4. **Unix / Linux** — автоматическая сборка и прогон тестов в облачном окружении Ubuntu через GitHub Actions.

## Графика и управление

- **Графика:** псевдографический вывод в терминал/консоль (`#` — стены, `@` — игрок, `$` — ящики, `.` — цели, `*` — ящик на цели).
- **Управление:** клавиатура (`Стрелки` или `WASD` — движение, `R` — перезапуск уровня, `ESC` — выход).

## Автоматизированное тестирование (`tests/`)

В файле `tests/test_vm.c` реализованы два уровня проверки:
1. **Модульные тесты (Unit tests):** проверка арифметики на стеке, условных переходов, работы с памятью и корректности декодирования Big-Endian.
2. **Фаззинг-тестирование (Fuzzing):**
   - `5 000` случайных последовательностей нажатий клавиш в игре Sokoban.
   - `5 000` случайных мутаций байт-кода (проверка защиты от переполнения стека, перезаписи кода программы и зависаний).

## Сборка и запуск

### 1. Генерация байт-кода игры
```bash
python game/build_rom.py
```

### 2. Сборка и запуск тестов (CMake + CTest)
Для Windows (MinGW):
```bash
cmake -G "MinGW Makefiles" -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Для Linux / macOS:
```bash
cmake -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

### 3. Запуск игры на Windows
```bash
./build/sokoban.exe
```
